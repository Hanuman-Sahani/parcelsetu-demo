# ParcelSetu — Clickable Demo

Clickable mockup of a parcel delivery platform for shopkeepers: in-city delivery (Porter / own delivery boys) and city-to-city delivery by railway through agents.

**Open the demo:** `index.html` (or `ParcelSetu_Demo.html`). Works on desktop and mobile browsers.

Logins in the demo: Admin, Shopkeeper, Delivery Boy, Railway Agent, plus a public parcel tracking page.

All names, numbers and amounts are sample data. Nothing is saved.
